# Archive.org Downloader

أداة تحميل متعددة الصيغ من archive.org مع دعم اللغة العربية والإنجليزية والتحميل المتوازي السريع.

⚠️ تنبيه مهم ⚠️

استخدم هذه الأداة بما يرضي الله سبحانه وتعالى، واتقِ الله فيما تقوم بتنزيله أو نشره.

الرجاء عدم استخدام الأداة في تنزيل أو نشر أي مواد محرمة أو مخالفة للشريعة الإسلامية.

واجعل استخدامها فيما ينفع المسلمين من:
- العلم النافع
- الكتب الإسلامية
- المحاضرات
- الأناشيد المباحة
- المواد التعليمية المفيدة

وكن سببًا في نشر الخير والفائدة.



# المميزات

* تحميل أكثر من صيغة بنفس الوقت
* دعم اللغة العربية والإنجليزية
* اختيار عدد التحميلات المتزامنة
* إنشاء مجلد تلقائي باسم المحتوى
* تجاوز الملفات الموجودة مسبقًا
* تنظيف أسماء الملفات تلقائيًا
